# Acoustic_analysis
Acoustic Dosimetry scans plotting code CLEAR CERN


This repository includes the main Python analysis used for "Characterisation of Acoustic Dosimetry for Very High Energy
Electron Beams at CERN CLEAR" technical report by Traian Tus

The acquisition pipeline and major statistical analysis portions were performed in MATLAB on internal computers

The scripts here are used for supporting dose calibration and data analysis of various systematic scans performed
